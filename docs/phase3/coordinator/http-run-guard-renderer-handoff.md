HTTP94 report, and independently pinned dependency bytes. It checks the original
source/report joins, reconstructs all seven exact installed predecessors using
literal count-checked reversible changes, verifies their actual report file pins,
then returns only the seven successors. It never opens/discovers files, imports a
historical stager, imports/executes generated code, installs output or manufactures
a report. The three measurement source-name sets are the same supplied bounded
inventory; their final installed completeness remains a Root review obligation.

The generated HTTP caller begins lazily after its existing first-callback policy,
health/revocation, claim and deadline checks, before decision finalization/connect.
It preserves all canonical refusal codes and chooses the first actual unprefixed
code for the single terminal journal field. Public client finish/close precede the
original broker lock release. An actual client interrupt/MemoryError is retained
before the frozen transport can replace it and restored after transport unwinds.
Cleanup/retention failure invalidates the pending ordinary BLOCK return.

The generated measurement configure captures immutable plan/process bytes and
original owner identity. Begin captures original pending bytes. The public
pre-final accessor checks original owner, actual process, both plan aliases,
pending equality and request/grant pins, preserving source/input checks and the
8192-byte credential bound. It acquires no lock and restamps no acceptance time.

The generated service retains the actual protected raw measurement/grant input
and calls the repaired public fixture credential reader. Bootstrap receive/take,
client configure and transfer-owner close occur before existing startup readiness
and serve. A successful take is retained strongly even if later argument handling
or configure fails; the module never independently closes client-owned handles.
Receive/take failures are not closed again. Supplemental HTTP/service getters
detach containers but preserve actual exceptions/owners, retain one process-local
attempt, and provide no reset or external durable-retention claim.

Both HTTP-specific reason consumers independently add only the twelve frozen
BROKER_RUN codes for canonical nonempty BLOCK/NOT_PERFORMED vectors with policy
ALLOW and null payload decision. Existing policy/transport/receipt joins remain.
Shared create/effective reason sets are untouched.
